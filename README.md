# 21點 Blackjack 
---

## 專案簡介
本專案為使用 C# Windows Forms 開發的經典撲克牌遊戲「21點 (Blackjack)」。
遊戲具備完整的核心規則與判定邏輯，並結合了圖片動態載入與音效播放功能，提供流暢且直覺的遊戲體驗。專案底層採用嚴謹的**物件導向 (OOP)** 架構設計，將卡牌與牌堆邏輯獨立封裝，提高程式碼的維護性與可讀性。

## 遊戲特色與功能
* **標準 21 點規則：** * 精確計算點數，實作了「A 可以視為 1 點或 11 點」的動態轉換邏輯。
  * 莊家 AI 判斷：當玩家停牌後，莊家若小於 17 點將自動持續要牌。
* **生動的聲光效果：**
  * 支援撲克牌面圖片動態載入。
  * 遊戲過程中包含「洗牌、要牌、停牌、勝利、失敗」等多種音效回饋。
* **流暢的使用者體驗 (UI/UX)：**
  * 實作莊家「蓋底牌」機制，確保遊戲公平性，直到玩家停牌後才翻開。
  * 莊家自動補牌時導入 `async` / `await Task.Delay()` 非同步設計，發牌具備時間間隔，且不卡死畫面。

## 執行說明
1. 確保電腦已安裝 Visual Studio (建議版本 2019 或 2022) 以及 .NET Framework。
2. 將本專案 Clone 或下載至本地端。
3. 進入資料夾，點擊 `1131435_HW2_BlackJack.sln` 開啟專案。
4. 點擊 Visual Studio 上方的「開始 (Start)」按鈕即可編譯並執行遊戲。
5. **遊玩方式：**
   * 點擊「重新開始」進行發牌。
   * 點擊「要牌 (Hit)」抽取一張新牌，若超過 21 點即爆牌失敗。
   * 點擊「停牌 (Stand)」結束回合，由莊家翻開底牌並自動補牌決勝負。
